# VOTING APP

Create your own pools, let people decide with their vote.

![thumbnail](https://res.cloudinary.com/dhbig9jt8/image/upload/v1731422668/thumbnail-voting_app_pgc3sm.png)

## Features

This monorepository app has two main parts:
Frontend and Backend.
This module allow people to create pools and let people vote on them.
They can see the results in real time and share the pool with a link. It is possibly since the app uses websockets to update the results as it happens.
Use workcloud to show the pools and the results.
Upstash to store the pools and the votes.
